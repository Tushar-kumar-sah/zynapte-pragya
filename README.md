# Pragya School ERP — Full React.js Website

> **Empowering Schools. Enriching Futures.**  
> Built strictly in **React.js** (pure React + Vite + React Router, zero Next.js).

This repository contains the complete, production-ready website for **Pragya School ERP**, engineered to the specifications of the *Website Strategy / Copy Deck / UI Direction* brief and competitor research roadmap.

---

## ⚡ Quickstart

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open **`http://localhost:3000/`** (or the port shown in your terminal).

### 3. Build for Production
```bash
npm run build
```
Creates an optimized, minified production build in `dist/`.

### 4. Preview Production Build
```bash
npm run preview
```
Runs the production build on **`http://localhost:3080/`**.

## 🔒 Accuracy & Regulatory Guardrails Enforced

1. **APAAR Differentiator:** Pragya prepares and tracks student demographic data, checks consent, and exports clean CSV sheets. Authorized government systems (**UDISE+** and **DigiLocker**) handle actual submission and ID generation.
2. **Aadhaar Privacy:** Pragya never stores student Aadhaar numbers in the APAAR preparation record; local checks strictly use name, DOB, and linked guardian mobile.
3. **Roadmap Transparency:** Dedicated parent web portal, direct DigiLocker/UDISE+ connectivity, parent-facing online payment checkout, and telecom SMS/push delivery are explicitly labeled as **Planned Roadmap** items.
4. **Grounded Claims:** No fabricated client counts, testimonials, or certifications.
